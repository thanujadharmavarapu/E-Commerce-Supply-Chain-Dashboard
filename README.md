# E-Commerce Supply Chain Performance Dashboard

An interactive **Power BI dashboard project** developed to analyze
e-commerce supply chain operations, inventory, delivery performance,
transportation, warehouse efficiency, and executive-level performance
indicators.

The project was developed across four milestones, covering data
preparation and modeling, inventory and delivery analysis,
transportation analysis, and warehouse/executive performance analysis.

## 🚀 Project Highlights

### Milestone 1 --- Data Modeling & KPI Foundation

-   Loaded and cleaned the e-commerce supply chain dataset.
-   Prepared the Power BI data model and relationships.
-   Created foundational DAX measures.
-   Built the initial supply chain performance dashboard.
-   Analyzed shipment volume, delivery performance, customer ratings,
    product cost, and logistics distribution.

### Milestone 2 --- Inventory & Delivery Analysis

-   Created an Inventory Analysis dashboard.
-   Added inventory KPIs and warehouse/category analysis.
-   Created inventory trend and detailed inventory views.
-   Built Delivery Performance Analysis.
-   Added on-time versus delayed delivery analysis.
-   Added warehouse-level delivery comparison.
-   Added trend, drill-down, and variance analysis.

### Milestone 3 --- Transportation Analysis

-   Added transportation-focused KPI cards.
-   Analyzed supplier-wise shipment volume and quality.
-   Analyzed carrier-wise transportation cost.
-   Analyzed route-wise transportation cost.

-   Built a Warehouse Efficiency report.
-   Added operational KPI cards for warehouse performance.
-   Built an Executive Overview dashboard.
-   Added operating cost and executive-level operational views.
-   Added interactive slicers for dashboard analysis.
-   Added a detailed table for performance inspection and dashboard

## 🔧 Setup & Installation

### Prerequisites

Install **Microsoft Power BI Desktop** on your Windows system.

### Steps

1.  Clone or download this repository.
2.  Open `Ecommers-dashborad.pbix` using Power BI Desktop.
3.  Ensure the source dataset is available if the report requires a data
    refresh.
4.  Review the data model and DAX measures.
5.  Use the report-page navigation to explore the milestone dashboards.
6.  Use the slicers and interactive visuals to filter the analysis.

## 🎯 Project Objective

The objective of this project is to build an interactive business
intelligence solution for understanding and monitoring e-commerce supply
chain operations. The dashboards bring together inventory, delivery,
transportation, warehouse, and executive-level analysis into a single
Power BI reporting solution.

------------------------------------------------------------------------

## 📈 Dashboard Design

The dashboards use a consistent dark-themed interface with:

-   KPI cards for important performance indicators
-   Bar and column charts for category and warehouse comparisons
-   Line charts for trend analysis
-   Donut and pie charts for distribution analysis
-   Tables for detailed record-level analysis
-   Slicers for interactive filtering
-   Drill-down and variance analysis for deeper exploration
