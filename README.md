# E-Commerce Supply Chain Performance Dashboard

An interactive Power BI dashboard engineered to analyze and optimize supply chain efficiency, logistics performance, and warehouse delivery metrics for an e-commerce platform.

## 📊 Dashboard Preview

![E-Commerce Supply Chain Dashboard](Dashborad%20preview.png)

---

## 🚀 Key Metrics & Insights

* **Total Shipments:** Evaluated **11K** total shipments to track volume distribution across multiple operational lines.
* **Delivery Performance:** Monitored a **59.67% On-Time Delivery Rate**, identifying significant operational bottlenecks.
* **Financial Capital:** Tracked **₹820.33K in Pipeline Capital** currently tied up across fulfillment channels.
* **Customer Experience:** Analyzed a **3.0 Average Customer Rating** alongside **45K Support Calls** to target service improvement areas.
* **Logistics Analysis:** Segmented delivery priorities across transportation types (**Ship**, **Road**, and **Flight**), identifying **Ship** as the primary high-volume carrier with **7,462** total items.

---

## 🛠️ Tech Stack & Skills Demonstrated

* **Data Visualization:** Power BI Desktop
* **Data Transformation:** Power Query (ETL process)
* **DAX Formulas:** Calculated columns and measures for custom KPIs
* **UI/UX Design:** Dark-themed dashboard architecture featuring custom card layouts and clean grid alignments

## 🔧 Setup & Installation

1. **Prerequisites:** Ensure you have the latest version of [Power BI Desktop](https://microsoft.com) installed.
2. **Clone the Repo:** Clone this repository to your local machine.
3. **Open the Project:** Launch the `.pbix` file directly inside Power BI Desktop to interact with the filters, underlying data model, and DAX measures.
